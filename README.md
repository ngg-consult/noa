# סדר היום – לו"ז בוקר אוטומטי

אפליקציה שמציגה כל בוקר את סדר היום, עם שעה לכל משימה. היא קוראת את היומן והמיילים מ-Outlook, מתעדפת לפי מטריצת אייזנהאואר ועקרונות GTD, ומשבצת את המשימות בחלונות הפנויים בין הפגישות.

## מה האפליקציה עושה

| דרישה | מימוש |
|---|---|
| קריאת מקורות | יומן ומייל Outlook דרך מחבר Microsoft 365 של claude.ai. וואטסאפ ומשימות נוספות מוזנים בהדבקה (ראו "מקורות"). |
| תעדוף | Claude מסווג כל מייל: הצעד הבא, משך, הקשר (מחשב / טלפון / פגישה / בחוץ), דחוף, חשוב, למי אפשר להאציל, ולקוח. מזה נגזר רבע במטריצה. |
| חדש קודם | תוספת ציון שדועכת עם גיל הפריט (מחצית בערך תוך 17 שעות). פריט חדש מקבל עדיפות גבוהה יותר בתוך אותו רבע. |
| GTD | משימה של עד 2 דקות מקודמת לביצוע מיידי. משימה דחופה שאפשר להאציל מקבלת 5 דקות להעברה בלבד. לא דחוף ולא חשוב לא משובץ. |
| שיבוץ | משימה בעדיפות גבוהה מקבלת את החלון הפנוי המוקדם ביותר, עם 5 דקות מרווח סביב כל פגישה. ליד כל פגישה מופיעה שורת הכנה אחת. |
| תיקונים במילים | כל תיקון מתורגם לכלל מובנה, מוצג לאישור ("הבנתי: …") ונשמר בקובץ הכללים. כל הכללים מופעלים מחדש בכל בוקר. |
| בוצע / לא בוצע | "בוצע" משחרר את הזמן וסדר היום נבנה מחדש מעכשיו. "לא בוצע" מעביר את המשימה לחלון הפנוי הבא, ואם אין כזה למחר. |
| רענון אוטומטי | בפתיחה הראשונה של כל בוקר (או אם המסך פתוח, החל מ-05:00) היום נבנה מחדש. מה שלא בוצע אתמול עובר אוטומטית. |

## מבנה

```
app/engine.js     לוגיקת תעדוף ושיבוץ – פונקציות טהורות, נבדקות ב-Node
app/app.js        ממשק, חיבור ל-Outlook דרך המחבר, קריאות ל-Claude, שמירה
app/index.html    תבנית ועיצוב (RTL, מצב בהיר וכהה, מותאם לטלפון)
build.mjs         מאחד הכול לקובץ אחד: dist/morning-plan.html
test/             בדיקות יחידה למנוע
rules.example.json  מבנה קובץ הכללים
```

הרצת בדיקות ובנייה:

```
node --test test/*.cjs
node build.mjs
```

הקובץ `dist/morning-plan.html` מתפרסם כ-Artifact פרטי ב-claude.ai. רק שם יש לו גישה למחברים, ל-Claude ולשמירה.

## מקורות ואיך לחבר אותם

| מקור | מצב | איך לחבר |
|---|---|---|
| יומן Outlook | מחובר | מחבר Microsoft 365 ב-claude.ai. בפתיחה הראשונה הדף יבקש אישור לקרוא ממנו. |
| מייל Outlook | מחובר | אותו מחבר. נקראים מיילים מ-3 הימים האחרונים, בלי הזמנות לפגישות ובלי מיילים שנשלחו ממך. |
| Gmail / Google Calendar | לא מחובר | claude.ai ← הגדרות ← Connectors ← Gmail / Google Calendar ← Connect. דורש הרחבה קטנה בקוד אם רוצים גם אותם. |
| וואטסאפ | אין חיבור ישיר | ל-WhatsApp אישי אין API רשמי לקריאת הודעות. API של WhatsApp Business מיועד למספר עסקי בלבד. הפתרון: להדביק הודעות בתיבה "הוספת משימות", ו-Claude מחלץ מהן משימות. |
| Microsoft To Do / Planner | לא נחשף במחבר | מחבר Microsoft 365 הנוכחי לא כולל כלי משימות. משימות נוספות נכנסות דרך תיבת "הוספת משימות". |

## אבטחה ופרטיות

- נתוני המייל והיומן לא נשמרים בקוד ולא נכנסים ל-Git. הם נקראים בזמן אמת עם ההרשאות של המשתמשת המחוברת.
- המצב (לו"ז, סימונים, כללים) נשמר בנתיב `data/users/<id>/`, שפרטי למשתמשת גם אם הדף משותף.
- לסיווג נשלחים ל-Claude רק נושא, שולח ותקציר של עד 300 תווים מכל מייל, בתוך חשבון claude.ai של הארגון.
- כללים לא נמחקים. אפשר להשבית ולהפעיל אותם מחדש, כך שנשמר תיעוד מלא.
